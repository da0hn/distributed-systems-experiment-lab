## Sobre este arquivo

As instruções para editar `docs/` vivem em [`AGENTS.md`](AGENTS.md), importado na primeira
linha. Edite lá, nunca aqui.

Este arquivo existe porque o Claude Code descobre instruções de subdiretório procurando
`CLAUDE.md`, e não `AGENTS.md`. Sem ele, o conteúdo de `docs/AGENTS.md` deixaria de ser
carregado ao trabalhar nesta pasta. Vale a mesma divisão da raiz: o que for específico do
Claude Code entra aqui, o que valer para qualquer agente entra no `AGENTS.md`.
